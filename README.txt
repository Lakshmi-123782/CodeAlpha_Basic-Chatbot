CODEALPHA INTERNSHIP - TASK 4
BASIC RULE-BASED CHATBOT
===============================================

PROJECT OVERVIEW
----------------
This project is a simple rule-based chatbot developed in Python
for the CodeAlpha Python Internship.

The chatbot uses if-elif conditions, functions, regular expressions,
loops, input/output, randomization, and time delay.

NEW ATTRACTIVE FEATURE
----------------------
Emoji responses have been added to selected answers, especially:
- Greetings
- Jokes
- Silly/fun questions
- Secret answers
- Funny answers
- Fear/bug answers
- Boredom suggestions
- Career advice
- Goodbye messages

This makes the terminal output more friendly and attractive while
keeping the project simple and professional.

FEATURES
--------
1. Rule-based conversation
2. 17 supported questions/topics
3. HELP command
4. Fun and silly questions
5. Multiple responses for each category
6. No repeated response until all responses in that category are used
7. Emoji-enhanced responses
8. Silent 3-second delay before exiting
9. Supports BYE, EXIT, and QUIT
10. Handles Ctrl+C / EOF safely
11. Uses only Python standard-library modules

FILES
-----
chatbot.py
README.txt

REQUIREMENTS
------------
Python 3.x

No external packages are required.

HOW TO RUN
----------
1. Open the project folder.
2. Open Command Prompt / Terminal in that folder.
3. Run:

   python chatbot.py

SUPPORTED COMMANDS
------------------
Type HELP to display the supported questions.

Type BYE, EXIT, or QUIT to close the chatbot.

EXAMPLE
-------
You: tell me a secret
Chatbot: My secret is... I secretly enjoy talking to humans! 🤫😄

You: tell me something funny
Chatbot: Why was the computer cold? Because it left its Windows open! 🪟🥶😂

You: are you afraid of anything
Chatbot: Maybe bugs... especially the ones in my code! 🐛😂
